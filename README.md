# Somalia Gemstone and Minerals

Free static website ready for GitHub Pages.

## Publish
1. Create a public GitHub repository named `somalia-gemstone-and-minerals`.
2. Upload `index.html`.
3. Upload the `images` folder when you have photos.
4. Go to Settings → Pages.
5. Select Deploy from a branch → `main` → `/ (root)` → Save.
6. Your free GitHub Pages address will appear there.
